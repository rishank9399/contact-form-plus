# Contact Form Plus

make a web app just the frontend in react.js (vite). The web app should contain a form
Name with only alphabets,
phone number with only numericals and only 10digit
email id 1,
email id 2,
(both email should be different)
Address with only 50 words input,
Attachment only docs and doc.x files
Captcha
Submit button

Make the website clean fresh and professional
